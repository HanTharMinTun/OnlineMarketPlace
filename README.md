# Online Market Place Website

A marketplace for buyer and seller to buy and sell efficiently.

- React + Vite (Frontend)
- Node.js (Backend/API)

---

# Requirements

Install these before starting:

- Git
- Node.js LTS
- npm
- VS Code (recommended)

---

# 1. Clone Repository (Everyone)

Open Terminal / PowerShell and run:

```bash
git clone https://github.com/HanTharMinTun/.git
````

Enter the project:

```bash
cd 
```

---

# 🪟 Windows Setup

Follow all steps in this section.

---

## Step 1: Install Git

Download Git:

[https://git-scm.com/downloads](https://git-scm.com/downloads)

After installation, verify:

```powershell
git --version
```

---

## Step 2: Install Node.js (Recommended)

1. Download **NVM for Windows**:

[https://github.com/coreybutler/nvm-windows/releases
](https://github.com/coreybutler/nvm-windows/releases/download/1.2.2/nvm-setup.exe)

2. Install NVM using the installer.
   

4. Install the required Node.js version (replace with your version):

```powershell
nvm install 22.14.0
```

4. Use that version:

```powershell
nvm use 22.14.0
```

5. Verify:

```powershell
node -v
npm -v
```

Expected output:

```text
v22.14.0
```

---

## Step 4: Install Frontend

Go to frontend folder:

```powershell
cd OnlineMarketPlace
```

Install packages:

```powershell
npm install
```
Expected node version v22.14.0


Start React:

```powershell
npm run dev
```

Open browser:

```
http://localhost:5173
``` 
When the server is working, shutdown the server again with q+Enter in terminal!
---



## Step 8: Run Website

Open another terminal:

```powershell
cd OnlineMarketPlace
```

Run:

```powershell
npm run dev
```

Your website is ready.

# 🐧 Linux Setup (Ubuntu/Debian)

Follow all steps in this section.

---

## Step 1: Install Git

```bash
sudo apt update
sudo apt install git
```

Verify:

```bash
git --version
```

---

## Step 2: Install Node.js using NVM

Install NVM:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

Restart terminal.

Check:

```bash
nvm --version
```

Install Node LTS:

```bash
nvm install v22.14.0
nvm use v22.14.0
```

Verify:

```bash
node -v
npm -v
```
Expected node version v22.14.0

---

---

## Step 4: Install Frontend

Go to frontend:

```bash
cd OnlineMarketPlace
```

Install:

```bash
npm install
```

Run:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
